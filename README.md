
# Solar System Explorer

An interactive 3D educational game built with HTML, CSS, JavaScript and Three.js.
Explore the planets, use a physics calculator, complete missions, and test yourself in a quiz.

## Features

- 3D solar system with textured planets, axial tilts, and Saturn's rings
- ISS model orbiting Earth
- Planet explorer (click any planet)
- Physics calculator: weight, orbital period (Kepler's third law), escape velocity
- 6 missions with scoring, and an 8-question quiz
- Sound effects and a mobile-friendly layout

## Run it locally

The game uses ES modules, so it must be served, not opened by double-clicking.

1. Open the folder in VS Code and click **Go Live** (Live Server extension), or
2. Run `python -m http.server 8000` in the folder and visit http://localhost:8000

## Tech

HTML, CSS, JavaScript, Three.js 0.160 (loaded from a CDN)
